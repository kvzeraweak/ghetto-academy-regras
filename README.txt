# Ghetto Academy — Site de Regras MTA

Pacote HTML independente, com visual inspirado na identidade enviada do Ghetto Academy.

## Estrutura
- `index.html` — página principal.
- `styles.css` — visual, responsividade e tema verde/preto.
- `script.js` — navegação por seções, menu mobile e busca.
- `assets/ghetto-cover.png` — imagem enviada usada no destaque.
- `assets/ghetto-icon.png` — imagem enviada usada como ícone.

## Como usar
Abra `index.html` para testar localmente.

Para publicar gratuitamente, envie a pasta para um serviço de hospedagem estática, como GitHub Pages, Netlify ou Vercel.

## Conteúdo
As regras e tempos de punição são um modelo inicial. Revise e ajuste os tempos, termos e regras para o regulamento definitivo do Ghetto Academy antes de publicar.
